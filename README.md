# 🛡️ ChainGuard — Multi-Chain DeFi Wallet Risk Analyzer

AI-powered wallet risk analysis on Ethereum & Arbitrum, verifiable on-chain via OpenGradient's TEE nodes.

## 🌐 Live Demo
https://web-production-bae3b.up.railway.app

## ⚡ Features
- Multi-chain support (Ethereum + Arbitrum)
- AI risk scoring (0-100) via OpenGradient TEE
- Real blockchain data via Etherscan V2 API
- Agent with 3 tools (balance, transactions, tokens)
- x402 payment protocol
- On-chain verified inference

## 🔧 Tech Stack
- Backend: Python Flask (Railway)
- Frontend: HTML + Tailwind CSS
- AI: OpenGradient SDK (GPT-4o via TEE)
- Data: Etherscan V2 API

## 🚀 How It Works
1. Enter any Ethereum/Arbitrum wallet
2. Agent fetches real blockchain data
3. OpenGradient TEE analyzes risk
4. Get verified risk score + recommendations

## 🔐 OpenGradient Integration
- TEE-secured inference (AWS Nitro Enclave)
- x402 payment protocol
- On-chain hash verification
- Verifiable AI outputs
